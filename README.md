
# StarRDP - Premium RDP & VPS Solutions

A modern, animated web application for selling RDP and VPS services, built with React, TypeScript, and Framer Motion.

## Features

- ✨ Modern UI with stunning animations
- 🎨 Beautiful gradient designs and cyber aesthetics
- 📱 Fully responsive design
- 🔒 Admin authentication system
- 🛒 Shopping cart functionality
- 💳 Payment integration ready
- 🚀 Optimized for Replit deployment

## Quick Start

1. Click the "Run" button to start the development server
2. The app will be available at the preview URL
3. Admin login: fxpl.hi2@gmail.com / Starkaowner@123

## Deployment

This app is optimized for Replit deployment:
- Static files are built to `dist/public`
- Server runs on port 5000
- All routing handled by React Router

## Tech Stack

- React 18 + TypeScript
- Framer Motion for animations
- Tailwind CSS for styling
- Radix UI components
- Express.js backend
- Vite for building
